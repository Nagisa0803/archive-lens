Two tools, separate responsibilities

Archive Bridge runs locally and performs authorized authentication and collection. This public viewer processes ZIPs in your browser; it never asks for a game password or uploads your archive.

02 / GUIDE

Create your first backup

  1. Download the matching Archive Bridge release

    Open Archive Bridge releases, choose the package for your operating system and architecture, and extract it. Platform support and known limitations are documented in the collector repository.

  2. Start the local collector

    Run the application on your computer and open the local address it displays. Choose an output folder. If setup asks for a supported game APK, select your own installation package; no APK is included in these repositories.

  3. Sign in using your own game account

    Configure account linking in the game first. Enter the ID and password only into your trusted local collector, review its scope, and explicitly start collection. Never put credentials in GitHub Issues, chat, or this public viewer.

  4. Wait for completion and save the ZIP

    A configured password alone is not a backup. Wait for the collector to finish, inspect its coverage summary, and save the resulting ZIP. Keep the original copy, then import it into Archive Lens.

03 / GUIDE

Import and explore

  1. Select Import backup

    Choose an account ZIP, a snapshot JSON, or a complete User/Get JSON. On desktop, you can also drag the file into the dialog. A photo-links JSON is a supplement and belongs in the Photos page.

  2. Wait for the success message

    The browser supports a ZIP up to 128 MiB, up to 128 MiB unpacked in total, and 64 MiB per member. Use your computer to handle larger files.

  3. Browse your content

    Select a character to see every owned card for that character; select a card for details. Teams show saved positions. Resources show saved values. Costumes and additional hairstyles have their own gallery.

Appearance records

Costume-default hair records are separate from additional hairstyles. Missing independent images are not replaced with character portraits. Game names and original data remain in their original form when you change the interface language.

04 / GUIDE

Export an account ZIP

  1. Import and select an account

    Export is disabled until an archive is loaded. Choose the intended snapshot before exporting.

  2. Select Export archive

    The browser prepares the saved data and available generic thumbnails. Wait for the archive-ready dialog.

  3. Select Download account ZIP

    The ready dialog is not the download itself. Confirm that the ZIP appears in your browser downloads or Files app, then re-import it to check the result.

What the ZIP contains

It preserves the snapshot, original payloads and media already present in the input, plus thumbnails actually added during export. It cannot recreate a missing raw protobuf or photo original. Imported secrets are not inspected or removed from full backups; keep them private.

05 / GUIDE

Export photo URLs

  1. Check link coverage

    Photo IDs and asset IDs are not download URLs. Older packages may need a matching photo-links JSON, imported using Import photo links. A file for another account is rejected.

  2. Choose a format

    JSON

    Full mapping and records; can be imported again for the same account.

    CSV

    One row per photo with original URL, thumbnail URL and status.

    TXT

    Deduplicated original image URLs for download tools.

  3. Open or download an image

    Original and Thumbnail open the returned official URL in a new tab. Save the image using your browser. Opening the list never downloads all remote photos automatically.

A link list is not a full photo backup

Real samples have downloaded without cookies, game tokens or URL signatures. That does not prove every URL works anonymously or stays valid forever. Records with no returned URL stay visible; their paths are not guessed.

06 / GUIDE

Use your phone

  1. Save the ZIP to your phone

    Transfer it using a method you trust, then save it in Files or Downloads. A chat attachment preview may not support local file selection.

  2. Import it in a browser

    Open Archive Lens in your system browser, select Import backup, and choose the saved ZIP. Navigation and team layouts can scroll horizontally.

  3. Confirm exported files were saved

    Check Downloads or Save to Files. If an embedded chat browser blocks file downloads, use your system browser and keep the original ZIP.

Why a computer localhost address does not work on a phone

127.0.0.1 on your phone refers to the phone itself. Create the backup on the computer running Archive Bridge, then transfer the ZIP to your phone. Refreshing Archive Lens clears the imported session; import the ZIP again.

07 / GUIDE

Privacy and coverage

  • Archives are processed in the current browser and are not POSTed to the site.
  • Account data is not saved to localStorage or IndexedDB. The language choice travels in the URL.
  • Refreshing clears the imported session without deleting your original ZIP.
  • Public source contains generic code and assets, not account snapshots, ownership sets, private photo URLs or credentials.
  • Saving a complete User/Get response does not prove that every separate endpoint, photo original, message or phone history was captured.
08 / GUIDE

Troubleshooting

Pictures are missing after import

Check whether the record exists. Missing files cannot be recreated from an ID alone. Default hairstyle records may have no independent preview.

An export button is disabled

Load an account first. Photo export also requires actual image URLs. After refreshing, import the ZIP again.

A photo URL returns 403, 404 or a connection error

Keep the original record and check its source and collection time. Use only an authorized collection flow to update it; do not guess paths or remove access parameters.

Can this website sign in to the official game?

No. Use Archive Bridge on your own computer for authorized collection, then import the resulting ZIP here.

Can the ZIP restore my progress to the official game?

No. These tools browse and export archives; they do not write a ZIP back into an official game account.
